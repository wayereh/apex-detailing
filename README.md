# apex-detailing

EN: A demo project of a responsive landing page for a car detailing studio, created for my personal portfolio as a Frontend Developer. Built with clean HTML5, CSS3, and Vanilla JS, featuring an interactive service cost calculator, portfolio category filtering, and full mobile responsiveness.
